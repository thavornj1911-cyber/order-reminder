ทำไมต้องใช้ Firebase Cloud?

เมื่อคุณปิดคอมพิวเตอร์ โทรศัพท์จะไม่สามารถเข้า localhost ได้ แต่ด้วย Firebase Firestore (ใช้งานฟรี 100%) ข้อมูลจะถูกเก็บไว้บน Cloud ของ Google ทำให้เปิดเช็คหรือสั่งของผ่านมือถือได้ 24 ชั่วโมงแม้ปิดคอมพิวเตอร์ไปแล้ว!

เปิด Firebase Console
สำรองข้อมูล (JSON Backup) ดาวน์โหลดข้อมูลเก็บไว้ หรือนำไปเปิดเครื่องอื่น

วิธีเปิดดูในมือถือเมื่อปิดคอมพิวเตอร์

ดูได้ 24 ชั่วโมงจากทุกที่ ฟรี 100%

ทำไมเปิดผ่าน Localhost ไม่ได้เมื่อปิดคอม?

เมื่อปิดคอม เซิร์ฟเวอร์ในคอมจะหยุดทำงาน ดังนั้นหากต้องการเปิดดูผ่านโทรศัพท์ตลอดเวลา 24 ชม. สามารถนำโฟลเดอร์นี้ไปอัปโหลดขึ้นเว็บฟรีได้ภายใน 2 นาทีตามขั้นตอนด้านล่างนี้ครับ:

1 วิธีที่ง่ายที่สุด: ลากใส่ Netlify Drop (เสร็จใน 30 วินาที) แนะนำ
  1. เปิดเว็บ app.netlify.com/drop
  2. ลากโฟลเดอร์โปรเจกต์ แอปแจ้งเตือนสั่งของ ทั้งโฟลเดอร์ไปวาง
  3. จะได้ลิงก์เว็บ URL ทันที (เช่น https://my-order-reminder.netlify.app)
  4. ส่งลิงก์เข้าไลน์เปิดในมือถือได้เลย ใช้งานได้ตลอด 24 ชม. แม้ปิดคอม!
2 หรือผ่าน Vercel / GitHub Pages

สามารถสร้าง GitHub repository แล้วเปิด GitHub Pages (ฟรีตลอดชีพ) หรือ Deploy บน Vercel เพียงคลิกเดียว
